# 旅遊規劃（階段 5：地圖與天氣）
## 更新方式（從階段 4 升級）
把整包內容覆蓋到 GitHub 儲存庫。新增：vendor/leaflet/（地圖函式庫，已內建，離線可用）、js/geo.js。
更新後請「載入兩次」讓離線快取更新（第一次載入安裝新快取，第二次起生效）。不要清除「網站資料」。
## 階段 5 已完成
- 行程可設定位置：輸入地址按「查詢座標」（Nominatim），查不到或位置不對可在地圖上手動點選。
- 時間軸卡片右側顯示小地圖，點擊放大，可用地圖 App 開啟導航。
- 每日天氣（Open-Meteo）：優先用當天第一個有位置的行程，否則用目的地；總覽頁可查詢目的地座標。
  預報約涵蓋未來 16 天；過去日期顯示歷史天氣；離線顯示上次資料。
- 離線地圖：看過的地圖會自動快取（上限約 600 張）；時間軸底部有「預載地圖」，預載各地點周邊約 150 張。
