# 旅遊規劃（階段 1：骨架）
## 怎麼測試
- 最簡單：把整個資料夾放上 GitHub Pages，用電腦與手機開網址。
- 本機：在此資料夾執行 `python3 -m http.server 8000`，開 http://localhost:8000
- 也可雙擊 index.html（多數瀏覽器可用，但持久儲存與日後的離線快取需要 https 或 localhost）。
