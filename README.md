# 旅遊規劃（階段 6.2：臨時花費）
## 更新方式（從階段 5.1 升級）
把整包內容覆蓋到 GitHub 儲存庫。新增：manifest.webmanifest、icons/、i18n/dict.js、js/i18n.js。
更新後請「載入兩次」讓離線快取更新。不要清除「網站資料」。
## 階段 6 已完成
- PWA：安裝設定與圖示；旅行列表頁的「安裝成 App」區（Android 有安裝按鈕，iPhone 有加入主畫面說明）。
- 多語系：繁體中文（預設）、English、日本語。在旅行列表頁「語言與外觀」切換，會記住選擇。
  程式內文字維持繁體中文，由 i18n/dict.js 字典在顯示時翻譯；找不到翻譯的文字會維持繁體中文。
  日後要新增或修正翻譯，只需編輯 i18n/dict.js（格式：[繁體中文, English, 日本語]，{} 代表會變動的內容）。
- 外觀：跟隨系統／淺色／深色。
## 注意
- 使用者自己輸入的內容（行程名稱、備註等）不會被翻譯。
- 行程分類（景點、美食…）、行李預設類別、天氣描述等系統文字會隨語言顯示，但資料檔裡仍存中文，換語言不影響資料。

## 6.1 調整
手機版行程卡片：文字不再被擠在左側，小地圖靠右浮動，文字繞著地圖排列，地圖下方的空間改由文字使用。電腦版排版不變。

## 6.2 新增：臨時花費
費用頁新增「＋ 記一筆臨時花費」：項目名稱、金額與幣別、類別（沿用六類）、日期（旅行期間任一天，或不指定日期）、付款人、分擔方式（均分／指定部分人／每人指定金額）。
臨時花費一律計入總額、圓環圖、預算、分帳與費用明細（標示「臨時」，可直接編輯與刪除）；行程項目仍維持唯讀，要改請回時間軸。
資料存在旅行的 expenses 欄位，屬於共用的旅行資料，匯出入時會跟著行程走（舊資料沒有這個欄位也能正常開啟）。
