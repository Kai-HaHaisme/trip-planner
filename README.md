## 個人清單可分開匯出入
匯出：可選擇是否放進行李清單、願望清單。只有兩者都放進去才算「完整備份」並更新備份時間。
匯入：檔案含個人清單時會詢問是否匯入。覆蓋同一趟旅行時，預設保留你目前的清單。
覆蓋前會比對「行程版本時間」，你這邊較新時會警告。（只改個人清單不會改變行程版本時間）
